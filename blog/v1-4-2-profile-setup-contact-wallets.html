v1.4.2 — Profile Setup & Contact Wallets

Updated for Viper 1.5.34 (November 19, 2026)

What changed since this post. Where the post and the app differ, the app is right.

  • Changed: since 1.5.11 another user's wallet address is no longer shown in their profile (an App Store review requirement). You can copy their public key instead.
  • The wallet deep-link template described here was not found in the 1.5.34 app.

Viper 1.4.2 is a focused update that improves identity configuration and contact wallet visibility.

My Profile → Setup

Your profile now has a dedicated Setup screen. From there you can set a custom deep link template for your TON wallet address — controlling which external wallet app opens when someone taps your address.

The template uses the {address} placeholder, which gets replaced with your full TON address at open time. Any URL scheme is supported, so you can point it at Tonkeeper, Tonhub, or any other wallet app:

tonkeeper://transfer/{address}

A live Preview shows you exactly what the resolved link will look like before you save it — no surprises.

Contact Wallet View

When you open another user's profile, Viper now shows their linked TON wallet inline. If their wallet is deployed on-chain, you'll see a Wallet active badge alongside the address.

From that view you get two actions:

  • Copy address — copies the full TON address to clipboard
  • Open in — launches the address in the contact's configured wallet app (opens externally)

This makes it easy to send TON to a contact — tap Open in and Viper hands off the address to the appropriate external wallet app.
