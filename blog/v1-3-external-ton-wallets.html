v1.3 — Linking External TON Wallets

Updated for Viper 1.5.34 (November 19, 2026)

What changed since this post. Where the post and the app differ, the app is right.

  • Import Account takes an Account Key of 64 characters or a Recovery Phrase; the phrase brings back the TON wallet too.

Viper 1.3 adds support for displaying TON addresses in user profiles, and allows users to link existing TON-compatible addresses generated outside of Viper.

In practice: if you already have a TON wallet — generated by any tool, not just Viper — you can now import it by pasting the private key. Your TON address will then appear on your profile and become resolvable inside the app.

Why This Matters

Viper accounts are tied to an Ed25519 keypair. TON wallets are also Ed25519-based. The two are compatible — your TON wallet's private key is a valid Viper identity key.

This means advanced users can generate a wallet offline, audit the code themselves, and import the result into Viper — no trust in key generation required.

Generating a Wallet with tonutils-go

The script below creates a new TON wallet using tonutils-go and prints the private key you can import into Viper.

package main

import (
	"context"
	"crypto/ed25519"
	"encoding/hex"
	"fmt"
	"log"

	"github.com/xssnick/tonutils-go/liteclient"
	"github.com/xssnick/tonutils-go/ton"
	"github.com/xssnick/tonutils-go/ton/wallet"
)

func main() {
	// Generate new seed phrase (24 words)
	seed := wallet.NewSeed()

	pool := liteclient.NewConnectionPool()
	cfgURL := "https://ton.org/global.config.json"
	if err := pool.AddConnectionsFromConfigUrl(context.Background(), cfgURL); err != nil {
		log.Fatalln("config err:", err)
	}
	api := ton.NewAPIClient(pool)

	w, err := wallet.FromSeedWithOptions(api, seed, wallet.V4R2)
	if err != nil {
		log.Fatalln("wallet err:", err)
	}

	priv := w.PrivateKey() // ed25519.PrivateKey
	pub := priv.Public().(ed25519.PublicKey)

	fmt.Println("Seed phrase:   ", seed) // []string, store securely
	fmt.Println("Address:       ", w.WalletAddress().String())
	fmt.Println("Private key:   ", hex.EncodeToString(priv.Seed())) // 32-byte seed
	fmt.Println("Private (full):", hex.EncodeToString(priv))        // 64-byte
	fmt.Println("Public key:    ", hex.EncodeToString(pub))
}

Run it with go run main.go. You'll get a fresh 24-word seed phrase, the wallet address, and both the 32-byte and 64-byte representations of the private key.

Importing into Viper

Copy the Private key (32-byte hex) from the output and paste it in Accounts → Import account in Viper.

Activating Your Address

A TON wallet address only resolves on-chain after it has been deployed — that happens automatically when you:

  1. Send some TON to the address.
  2. Send any outgoing transaction from it.

Once deployed, your TON address will appear on your Viper profile and become discoverable by other users.

Keep your seed phrase safe. It controls both your Viper identity and your TON funds. Never share it.
