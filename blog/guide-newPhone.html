Moving to a new phone

What your key brings, and what stays here

Your key moves you

On the new phone tap Import Account and enter your Recovery Phrase or Account Key. Same public key, same @username; the phrase brings your TON wallet too.

Chats stay here

Your chats and contacts are kept on this phone only. The relay deletes each message once it is delivered, so it has no copy for the new phone.

Export them first

On the old phone: Settings → Security and Data → Encrypted Chat Backup → Export. Only your Account Key opens the file. Photos, videos and files go in with Pro.

Restore on the new phone

Import the same account first. Then Encrypted Chat Backup → Import, pick the file and restart Viper. Import is free, whatever the file holds.

Set these again

Route priority and the relay key are kept on this phone only. On the new one they start over: Relay first and the default relay.
