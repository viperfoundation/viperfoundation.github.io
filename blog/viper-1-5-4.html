Viper 1.5.4 — Faster App Startup & DHT Metadata Caching

Viper 1.5.4 is an infrastructure update focused on bootstrap performance.

What's new

  • App bootstrap improvements — the startup sequence is faster and more resilient.
  • DHT metadata caching — server metadata is now cached from the TON Distributed Hash Table. On subsequent launches, Viper can skip redundant DHT lookups and use cached data, reducing startup latency.

This is particularly noticeable on slower connections or when the TON network has higher-than-usual lookup times.
