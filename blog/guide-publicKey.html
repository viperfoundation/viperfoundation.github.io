Public key

How people find you and know it is you

Like a username

Paste someone's whole public key into Search and the relay finds them, with or without a @username. Yours works the same way.

It shows it is you

A message to you is encrypted to your key: only your Account Key opens it. The relay checks that every message really comes from the key it says, and over Bluetooth the two phones check each other's signatures.

Compare it once

A name can change, a key cannot. A nickname is just text, and a .ton name is a TON DNS domain, an NFT on the TON blockchain: Viper reads its current owner from the blockchain, so if the domain changes hands, the name points to someone else. To be sure a chat is the right person, compare the key in their profile with the one they gave you.
