Settings: what is where

Seven rows, each with its own screen

Seven rows

Profile → Settings: Appearance, Connectivity, Privacy, Subscription, Security and Data, Help, Advanced. Each row opens its own screen.

Appearance

Theme, Language, and Show TON Domains: the switch that lists .ton names in profiles.

Connectivity

Allow P2P and Allow Bluetooth turn those routes on or off; Route priority picks which goes first.

Privacy

Messages from Non-Contacts, Hide Typing and Send Read Receipts are free. Anon Mode and Hide Online Status are Pro: see Subscription.

Typing and Read Receipts

Hide Typing: nobody sees "typing…" from you. Turn off Send Read Receipts: senders see no read marks.

Security and Data

Your Account Key and recovery phrase, each behind Face ID. Then Enter via Face ID, Storage and Encrypted Chat Backup.

Help and Advanced

Help: Guides, the onboarding again, Network Diagnostics. Advanced holds the relay key. Delete Account and Erase All Data sit at the bottom of Settings.
