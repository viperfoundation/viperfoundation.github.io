Viper 1.5.6 — Message Selection & Shared Files in Profile

Updated for Viper 1.5.34 (November 19, 2026)

What changed since this post. Where the post and the app differ, the app is right.

  • Hold a message → Select up to this message picks it and every newer one; ✨ takes them to AI Chat; Delete for me removes them from this phone only.
  • A contact's media is under the name at the top of the chat → Shared in this chat → Media. Files someone shares from their profile are a separate feature, Shared Files.

Viper 1.5.6 brings two new features to chat and profile.

Message Selection

You can now select messages with precision:

  • Select exact message — tap to select a specific message for copying, forwarding, or deletion.
  • Select up to message — select a range of messages up to a given point in the conversation.

Shared Files in Profile

Each contact's profile now shows all files shared in the conversation in one place. No need to scroll through chat history — open the profile and browse everything that's been exchanged.
